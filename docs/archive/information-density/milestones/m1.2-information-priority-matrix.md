# EV-2 — P1 / M1.2 Information-Priority Matrix

**Date:** 2026-09-30  
**Status:** COMPLETE  
**Runtime changes:** None

## Decision model
Primary = needed to answer the page/state job and act now. Secondary = useful context that supports the job but must not compete. Exploratory = deeper detail/history available on demand. Deferred information must have an obvious discovery path. No content is marked redundant without evidence.

## Cross-page priority rules
1. Today is execution-first; Journey is orientation-first; Progress is evidence-first.
2. Goal context supports the job but never displaces the page's primary job.
3. Historical/detail surfaces are secondary or exploratory unless the current state makes them the immediate need.
4. A secondary section may remain visible when it materially supports the primary task; it must not visually compete with the primary action.
5. Exploratory information must be discoverable through clear labels, links, tabs, expandable sections, or existing navigation appropriate to the content—not hidden behind unexplained interactions.
6. Mobile uses the same priority model; it may change composition, not meaning.
7. State-specific needs override generic page ordering (for example review due, recovery, completion, errors).
8. No new dashboard or duplicate destination is introduced.
9. No data/API field is deleted merely because it moves out of the default view.
10. Redundancy remains unresolved unless repository evidence demonstrates the same information has no distinct user purpose.
