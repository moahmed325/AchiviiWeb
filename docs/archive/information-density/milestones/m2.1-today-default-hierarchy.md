# EV-4 — P2 / M2.1 Today Default Hierarchy

**Date:** 2026-09-30  
**Status:** COMPLETE  
**Milestone:** M2.1 — Today Default Hierarchy

## Objective
Recompose the default Today view so its first attention path answers “What do I do now?” with clear goal context, today's session, and the primary action.

## Implementation
- Reduced the goal heading from the strongest page heading scale to a supporting H3 treatment.
- Reduced spacing around goal context and the 90-day metadata row.
- Reduced the visual weight of the day counter so it supports rather than competes with the session.
- Increased the session title to H2 so the current task is the dominant content inside Today.
- Gave the primary action clearer separation from supporting actions through spacing while retaining the existing shared Button primitive.
- Kept the existing task surface, execution controls, session details, review, recovery, notes, focus mode, weekly glance, and navigation intact.
- Kept the existing page shell and P1 visual foundation; no new visual system or decorative treatment was introduced.

## Primary attention path
**Your goal → Today's current session → Start / primary execution action.**

The goal remains visible for context. The current session title now has stronger typographic priority. The existing Start control remains the primary execution entry point. Secondary actions remain available without becoming the visual focus.

## Preservation evidence
- Existing Today component behavior was retained.
- Existing FocusSessionModal start flow remains wired to the same action.
- Existing completion/recovery/review flows were not changed.
- Existing weekly glance and Roadmap/weekly-review navigation remain available.
- No API, database, task model, generation, analytics, or persisted-state changes were made.
- No content was deleted; progressive-detail behavior remains available for M2.2.
