## 1. Summary

- **State matrix (R1, EV-5).** Every Today state, and the Dashboard's status line for each miss state, now has at least one unit test and at least one browser test (section 3).
- **Gaps closed (R2).** 31 new browser cases: 13 general Today states in `todayStates.spec.ts` (`Every Today state is clean at 360-412 px (M3.4)`), plus 8 miss states, 5 Dashboard lines and 2 keyboard and motion cases in `missedSessions.spec.ts`. Each state case checks overflow at 360, 375, 390 and 412 px, axe after the fade-in, and 44 px controls. One new unit test covers the loading skeleton (`Home.test.tsx`).
- **Keyboard (R3) and reduced motion (R4).** One case walks the busiest Today (a swap offer plus "Set today aside") by Tab and checks that both dialogs trap focus, close on Escape and return focus. One case under `prefers-reduced-motion: reduce` checks that no finite animation lasts longer than 0.01 ms and nothing waits on one.
- **One shared `settled` (R5).** The local copies in `todayStates`, `weeklyReview`, `shell`, `progress` and `journeyMobile` were identical to the export in `shellFixtures.ts` and now import it. `expectCleanAt` moved there too, replacing identical copies in `missedSessions` and `lateTest`. Left alone because they differ: `onboarding.spec.ts` (no infinite-loop exception), `onboardingStates.spec.ts` (only animations inside `#main`) and `pathways.spec.ts` (takes a Locator).
- **`npm run e2e` (R6)** in `frontend/package.json`, noted in `CLAUDE.md`.
- **CI job (R7).** `e2e` in `.github/workflows/ci.yml` installs as the frontend job does, runs `npx playwright install --with-deps chromium`, runs the six Today specs on both projects and uploads `playwright-report/` and `test-results/` when it fails. In CI only, Playwright also writes the HTML report (`playwright.config.ts`).
- **Small fixes (R8), each covered by a new browser case:**
  1. Closing stretch: the "Benchmark achieved" and "In progress — Reinforcing" toggles were 39 px tall. Added `min-h-11` (44 px), as `AchievementScreen` and the shell already use.
  2. Closing stretch: the "Closing Stretch Approach" label and the upcoming day cells failed axe `color-contrast` (`text-text-muted` on a translucent surface). They now use `text-text-secondary`.
  3. Completed goal (Achievement hero): the four stat labels failed `color-contrast` for the same reason. They now use `text-text-secondary`.

  These are token swaps and a minimum height only. Copy, behavior and the backend are unchanged.

## 7. Discrepancies and decisions

- **Backend baseline.** The prompt's baseline is 52 files / 529 tests; `main` at `cf71710` has 47 / 431. Commit `358a315` (the research-pipeline removal) deleted the research test files after the prompt's baseline was taken. This milestone does not touch the backend.
- **Tab order** includes "Mark complete" (section 3). It is existing UI, not a change.
- **`settled` copies** in `onboarding`, `onboardingStates` and `pathways` behave differently, so they were not replaced (R5 says to confirm equivalence first).
- **A flaky axe scan found by CI.** The `e2e` job failed once, on the docs-only commit `1d3e2b7` ([run 37738374193](https://github.com/moahmed325/AchiviiWeb/actions/runs/37738374193)): `focus.spec.ts` › "accessibility: zero axe violations on start screen…" (desktop), with `color-contrast` on Today's Roadmap links. That existing test ran axe without waiting for Today's fade-in behind the dialog, so on a fast runner it measured the links mid-fade. Its three scans, and the completed-screen scan in `today.spec.ts`, now wait with the shared `settled` first. The inline copy of `settled` in `today.spec.ts` was replaced too (R5). Test-only change; `focus` and `today` passed 52/52 twice locally after it.
- **First baseline run.** It had 3 failures, all page reloads ("Execution context was destroyed", "element was detached") while I was editing files under `frontend/` during the run. The same tests passed in both untouched runs.
