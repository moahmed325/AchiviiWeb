# EV-5 — P2 / M2.2 Today Progressive Depth

**Date:** 2026-09-30  
**Status:** COMPLETE  
**Milestone:** M2.2 — Today Progressive Depth

## Objective
Defer appropriate supporting information while keeping it findable, without weakening the primary Today action.

## Implementation
- The full seven-day Week Glance is now closed by default.
- The existing weekly summary remains visible: week context and practice completion are still available without opening detail.
- A clearly labeled **Show week / Hide week** disclosure exposes the existing day-by-day controls when the user wants to explore them.
- The disclosure uses `aria-expanded` and `aria-controls`; the primary session and Start action remain outside the disclosure and immediately available.
- Existing detailed session disclosures for steps, minimum version, implementation intention, resource, and notes remain intact.
- No blanket accordion system was introduced.
- No information or functionality was deleted.

## Default vs explored state
**Default:** goal context → current session → primary action → concise weekly summary → discoverable week detail.

**Explored:** opening **Show week** reveals the existing seven-day navigation and preserves day selection behavior.

## Preservation
- Daily task selection remains unchanged once week detail is opened.
- Session start/completion, notes, timer/focus mode, review, recovery, Roadmap navigation, and persistence behavior were not changed.
- Existing secondary-detail disclosures remain available.
- No API, database, generation, analytics, or data-model changes were made.

## Validation

- Frontend TypeScript check (`npx tsc --noEmit`): **passed, exit code 0**.

## Acceptance mapping
- AC-4: secondary information no longer competes with the primary execution path by default.
- AC-5: deferred week detail remains discoverable through an explicit Show week control.
- AC-6: expanded detail retains the same weekly context and existing day controls.
