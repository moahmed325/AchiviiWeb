   - **What it does:** when `notLogged` or any `weekBehind` holds, and the week next week shows is harder than this week's target (number), or differs from it (deliverable), set that week to this week's target. On a light-test goal that means the next big week, with the light weeks before it filled as `checkWeeklyUpdate` fills them. Every later week stays as planned.
   - **Then:** run the result through the same climb and storing path as accepted targets (`safeStoredTargets`, `toStore`, read-back, week 12's entry), so a held week that forces week 12 down still gets WU-23's entry and sentence.
   - **What stays the same:** `outcome` stays `fallback`, `status` and `coachNote` stay null. `far_behind` is never applied on a fallback. No hold applies when next week shows week 12's target (WU-47). The `error` and `unreadable_targets` fallbacks stay exactly as now.

   - **The log:** add `held <not_logged|week_behind|not_logged,week_behind|none>` to the `[WeeklyUpdate]` line.
2. **WU-49, hold lines name the week the model sets.**
   - In `buildWeeklyUpdatePrompt`, the far_behind, unlogged-test and week-behind lines name the week the model sets: next week, or on a light-test goal `bigWeekFor(nextWeek)`, with "(next week shows it)". So does the bound's "A held week … may stay" clause.

   - The checks themselves don't change.
3. **WU-50, code keeps the metric and unit.**
   - In `readTarget`, for a number week: don't compare the metric. Accept the unit when it is missing, empty or the same unit (`sameUnit`, moved to one shared place, not copied). Return the current target with only the model's value.
   - A different unit, or a changed kind, stays a rejection, worded as now.
4. **WU-51, the held/raised sentence check.**
   - After the targets are filled, compare next week's target (`targets[0]`) with this week's target as shown (`input.target`). "Went up": harder for a number; a different description for a deliverable. "Stayed": the same.
   - It is a retry reason, worded so the retry can fix it, when either holds:
     - the sentence has `\b(held|kept|stays)\b` (case-insensitive) while next week went up;
     - the sentence has `\b(raised|up)\b` while next week stayed.
   - Nothing else: not "lowered", not other words.
   - It never applies to code's own sentences (`nextWeekSentence`, `week12Sentence`, the fallback lines).
5. **The label fix.**
   - `nextWeekSentence` gives the amount with no metric label: "Next week aims at 19.3 km, a safe step."
