## Orientation Rules Verified
1. Every rendered Journey state has a clear purpose/orientation rather than an unexplained data dump.
2. Active position is explicit at the top of the Journey experience.
3. Empty state explains what is missing and what to do next.
4. Completion is represented from the real goal status; no fabricated success state is introduced.
5. Future weeks expose strategic information only; daily sessions are generated only for the current week by the adapter.
6. Closing stretch remains understandable and distinct.
7. Desktop and mobile use the same JourneyData/state model and preserve the same priority model; their compositions differ intentionally.
8. Interactive phase disclosure retains keyboard-operable buttons, accessible names, `aria-expanded`, `aria-controls`, and visible focus styling.
