### Differences from the docs
- **The id reason leaves out the catch-all.** The prompt says "when no kind id matches the chosen template's ids at all". Every template has `catch_all`, so a profile that renames every kind but keeps `catch_all` would pass. I compare only the template's own kinds (not `catch_all`, `weekly_test`, `fixed_time_session`).
- **The warm-up word check looks at the first or the last words of a title, not only the start.** Real titles put the word at the end ("Easy indoor warm-up", "Workout metrics logging", "Tactics puzzles warmup"). A word in the middle does not count, so combined steps ("Dynamic warm-up and ramp-up pulls") pass.
- **The shared test answer in `recoveryProfileCall.test.ts` changed** (`portrait` → `project_piece`), because a profile with no template id now gets one retry. The tests that used it check the same things.
- **"Weekly test warm-up" counts as the test step.** `strategy_games-1` 6.1 in set 2 is titled "Weekly test warm-up". Both code (`TEST_STEP` in `weekPlan.ts`) and scoring (`score.ts`) treat any title starting "Weekly test" as the test step, so it is not scored: set 2 has 67 scored steps, not 68.
- **RULE-8 and the base prompt.** The base "WRITE THE WEEK" still asks for a short warm-up step and a short review step on the test day (no-profile path, unchanged as required). With a profile, the new line keeps that for the test day only.
