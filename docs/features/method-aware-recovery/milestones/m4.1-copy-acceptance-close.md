### Decisions I made
1. **Copy rules over all three pillars, not just `socialAdherence`.** The prompt says "every `coreRule` and `realWorldApplication`"; onboarding shows all three pillars (science, socialAdherence, proCoaching), so the test covers all of them for every preset. Other option: `socialAdherence` only, as before. All pass with no other copy change.
2. **Added `\bfail\b` and a plain `buffer` match to the copy-rule test.** Section 6 forbids "fail"; B-4 forbids a buffer. Other option: keep the old regex (`weekend buffer` only). Pillar *titles* are not checked (see Problems found: recomp's title).
3. **The exact-words tests match the whole `realWorldApplication` string** (`toBe`), so "the text before and after stays" is checked too. Other option: `toContain` the new sentence only.
4. **"No day gets longer" and "Nothing piles up" are not tied to a profile field**, because they hold for every kind. "With enough rest around it" is read as hard plus `restGapDays > 0`.
5. **plan-v2.md kept short:** one bullet per topic, few rule IDs, a pointer to `02-feature.md` for the detail.
