How pathway goals are found: code saves `canonicalMethodName = roadmap.method.name` (`routes/goal.ts:144`), which for a pathway is `presetMethod(preset).name`, the badge's last part (`lib/ai/roadmap.ts:781-788`, `checkRoadmapAnswer` `:711`). These are "Jack Daniels VDOT & 80/20 Polarized Base" for run10k (`presets/run10k.ts:20`), "Eric Helms Pyramid & Brad Schoenfeld Hypertrophy" for recomp (`recomp.ts:22`) and "Carmine Gallo Talk Like TED & Toastmasters International" for speech (`speech.ts:17`). The badges have not changed since they were added (`git log -G badge:` shows only `416cc09`). `isGoldenRail` is true for every pathway goal (`routes/goal.ts:143`, `:356`). Prisma `Json` columns are `JSONB` (`migrations/20260923020000_plan_v2`). Column names are Prisma's field names, quoted, and table names come from `@@map`.

**O1** (counts by week-1 target metric, unit and direction; samples hold only ids, status and numbers):
```sql
BEGIN TRANSACTION READ ONLY;
WITH pathway_goals AS (
  SELECT g.id, g.status, g.created_at, g.roadmap,
         CASE WHEN g."canonicalMethodName" ILIKE '%VDOT%' THEN 'run10k'
              WHEN g."canonicalMethodName" ILIKE '%Helms%' THEN 'recomp' END AS pathway
  FROM goals g
  WHERE g."planVersion" = 2
    AND g."isGoldenRail" = true
    AND (g."canonicalMethodName" ILIKE '%VDOT%' OR g."canonicalMethodName" ILIKE '%Helms%')
),
weeks AS (
  SELECT p.pathway, p.id AS goal_id, p.status, p.created_at,
         p.roadmap -> 'startingPoint' -> 'value' AS start_value,
         w1.target AS week1, w12.target AS week12,
         COALESCE((w1.test ->> 'light')::boolean, false) AS split_tests
  FROM pathway_goals p
  JOIN roadmap_weeks w1 ON w1."goalId" = p.id AND w1."weekNumber" = 1
  LEFT JOIN roadmap_weeks w12 ON w12."goalId" = p.id AND w12."weekNumber" = 12
)
SELECT pathway,
       week1 ->> 'kind' AS kind,
       week1 ->> 'metric' AS metric,
       week1 ->> 'unit' AS unit,
       week1 ->> 'direction' AS direction,
       split_tests,
       count(*) AS goals,
       count(*) FILTER (WHERE status = 'active') AS active_goals,
       (array_agg(
          jsonb_build_object(
            'goalId', goal_id,
            'status', status,
            'start', start_value,
            'week1', jsonb_build_object('value', week1 -> 'value', 'unit', week1 -> 'unit'),
            'week12', jsonb_build_object('value', week12 -> 'value', 'unit', week12 -> 'unit')
          ) ORDER BY created_at DESC))[1:3] AS samples
FROM weeks
GROUP BY 1, 2, 3, 4, 5, 6
ORDER BY pathway, goals DESC;
ROLLBACK;
```
`split_tests` separates goals created since weekly update M2.1. Their week 1 holds week 4's target (Q1), so their "week 1" value is week 4's.

**B-58** (live run10k, recomp and speech goals, and the stored tests of weeks not written yet: no `daily_tasks` rows for that week, jumped weeks left out):
```sql
BEGIN TRANSACTION READ ONLY;
WITH live AS (
  SELECT g.id, g.created_at, g."currentWeek",
         CASE WHEN g."canonicalMethodName" ILIKE '%VDOT%' THEN 'run10k'
              WHEN g."canonicalMethodName" ILIKE '%Helms%' THEN 'recomp'
              WHEN g."canonicalMethodName" ILIKE '%Talk Like TED%' THEN 'speech' END AS pathway
  FROM goals g
  WHERE g.status = 'active'
    AND g."planVersion" = 2
    AND g."isGoldenRail" = true
    AND (g."canonicalMethodName" ILIKE '%VDOT%' OR g."canonicalMethodName" ILIKE '%Helms%' OR g."canonicalMethodName" ILIKE '%Talk Like TED%')
),
unwritten AS (
  SELECT l.id AS goal_id, l.created_at, w."weekNumber", w.test
  FROM live l
  JOIN roadmap_weeks w ON w."goalId" = l.id
  WHERE w.jumped = false
    AND NOT EXISTS (SELECT 1 FROM daily_tasks d WHERE d."goalId" = l.id AND d."weekNumber" = w."weekNumber")
)
SELECT l.pathway,
       count(DISTINCT l.id) AS live_goals,
       count(DISTINCT u.goal_id) AS goals_with_unwritten_weeks,
       count(u.goal_id) AS unwritten_weeks,
       count(u.goal_id) FILTER (WHERE COALESCE((u.test ->> 'light')::boolean, false)) AS unwritten_light_tests,
       (array_agg(
          jsonb_build_object(
            'goalId', u.goal_id,
            'week', u."weekNumber",
            'type', u.test ->> 'type',
            'instructions', u.test ->> 'instructions',
            'passIf', u.test ->> 'passIf'
          ) ORDER BY u.created_at DESC, u.goal_id, u."weekNumber") FILTER (WHERE u.goal_id IS NOT NULL))[1:12] AS sample_tests
FROM live l
LEFT JOIN unwritten u ON u.goal_id = l.id
GROUP BY l.pathway
ORDER BY l.pathway;
ROLLBACK;
```
The test text is the roadmap model's text (or the pathway's own since M2.1), not the person's typed text. Neither query reads `rawGoal`, `answers`, notes, reflections or any `users` column.
